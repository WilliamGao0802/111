# 《BGL 的 AI 学习》使用说明

一个可以直接打开就用的 AI 学习网站。下面按「怎么启动 → 网站有哪些模块 → 每个模块怎么用」来讲。

---

## 一、启动网站（30 秒）

1. 打开文件夹 `bgl-ai-learning`
2. 双击 **`一键启动.bat`**
3. 等命令行出现 `✅ 服务已就绪` 后，浏览器会自动打开 <http://127.0.0.1:8501>
4. 用下面的演示账号登录

> 第一次启动会自动安装依赖、创建数据库并灌入演示数据，可能需要几分钟。
> 若提示依赖缺失，先双击 `初始化环境.bat` 再启动。
> 想换端口：命令行里执行 `set BGL_PORT=8600` 后再启动。

### 演示账号（密码都是 `123456`）

| 你想体验什么 | 用这个账号登录 |
|---|---|
| 完整管理功能（看板 / 审核 / 对账 / 运维） | `admin` |
| 学员视角（已有课程、进度、测评记录） | `fangyuan` |
| 讲师视角（开课、开播、看收益） | `liyuan` |

注册新账号也可以，密码必须是 **恰好 6 位数字**。

## 三、怎么用（按模块）

### 🏠 首页仪表盘
登录后第一屏就是它：上方是积分等级、已购课程、平均进度、测评平均分、关注粉丝；
下面依次是「继续学习」（直接跳回上次的课程）、推荐课程、最新新闻、热门直播、知识模块入口、
我的通知和最活跃用户榜。**没登录时**这里显示平台整体数据，可以先去逛逛再注册。

### 📚 AI 课程学习
- 顶部四个筛选：关键词、分类、类型、价格/评分/排序，右侧「刷新商品库」会把新上架课程同步成可售商品。
- 点任意课程进入详情：左侧是介绍与讲师，右侧是**价格卡**（未购买显示「立即购买 / 加入购物车」，
  已购买显示「继续学习」）。
- 未购买只能看标记「试看」的课时；购买后进入**学习区**：播放器、课时清单、
  「标记为已完成」，进度与证书自动更新。
- 页面底部有**学员评价**（已购可评星打分）和**课程问答**（提问后讲师在工作台回复）。

### 🧠 知识点讲解
六个模块共 24 个知识点：大模型基础、提示词工程、微调与对齐、RAG 与向量检索、
AI 应用开发、评估与安全。支持按模块/难度筛选和关键词搜索。
点进详情能看到「讲解 → 关键公式 → 示例代码 → 同模块关联 → 配套课程」。

### ✍️ 练习测评
- **练习模式**：选模块和题量，可勾选「优先重练错题」；答完提交立刻看解析，错题自动进错题本。
- **考试模式**：一次性交卷后统一公布成绩与解析。
- **错题本**：按错误次数排序，点「已掌握」移出，或一键「用错题重练一组」。
- **成绩记录**：得分趋势图 + 明细表。
- **薄弱点分析**：各模块正确率横向条形图，正确率最低的模块会给出复习建议。

### 📰 AI 新闻
顶部是当日精选 + 最近一年**最具影响力的 5 条**（按阅读量与点赞综合排序）。
下面是分类/标签/排序筛选和新闻列表，卡片上可直接点赞收藏。
详情页有正文、关键要点、相关推荐、原文出处链接。
最下方两个标签页是「我的收藏」和「往期新闻（一年前自动归档）」，
还可以把新闻导出成 **RSS** 文件订阅。

### 💬 讨论区
- **广场**：支持最新/最热/最多点赞排序，可按话题分区、标签、关键词筛选，还能「只看关注」。
- **发帖**：正文支持 Markdown；写 `@用户名` 会通知对方，写 `#标签#` 会自动提取标签；
  可以「存草稿」稍后继续。
- 进入帖子详情：点赞、关注作者、举报、作者可编辑删除（编辑后显示「已编辑」）；
  评论区支持**多级回复**，管理员还能置顶/加精。

### 📁 文件区
- **上传**：可一次选多个文件，设置分类（论文/数据集/代码/课件/其他）、标签和可见范围
  （公开 / 仅登录可见 / 仅自己可见）。单文件上限 50 MB，每人配额 500 MB。
- **全部文件**：搜索、分类筛选、按时间/大小/下载量排序；可多选后「打包下载」成 ZIP。
- **我的文件**：看配额进度条，支持**历史版本查看与回滚**（同名文件自动升版本）。
- 图片 / PDF / Markdown / 文本 / 代码支持**在线预览**；删除进**回收站**，30 天内可恢复。

### 📺 直播课堂
- 分「直播中 / 即将开播 / 回放」三个标签页展示；「即将开播」的场次可以**预约**，
  点「立即检查开播提醒」会模拟开播前 15 分钟推送。
- 进入直播间：深色沉浸式布局，左边是播放器和互动区，右边是弹幕聊天。
  登录用户可以发弹幕、点赞、申请连麦，讲师可发布投票并看到实时票数。
- 讲师在「开播（讲师）」标签页创建直播；直播结束后自动转为回放，
  如果关联了课程，回放会**自动生成一个课时**进入课程体系。
- 回放权限支持「免费 / 仅购课用户可看 / 限时免费」，非授权用户会被拦下并引导购买。

### 🛒 课程商城
- **商品**：单课 / 专栏 / 会员 / 单场票四种类型，可加购物车或直接「立即购买」。
- **购物车**：批量结算。
- **结算页**：填优惠券码（演示券：`WELCOME10`、`NEW20`、`VIP88`）、拖积分抵扣
  （100 积分 = 1 元，最多抵 20%），实时显示应付金额。选支付方式后提交订单，
  页面会给出**支付签名**，点「立即支付」完成（演示为本地模拟回调）。
  打开「模拟支付失败」可以体验失败提示与重试路径。
- **我的订单**：按状态筛选，待支付可继续支付，已支付可申请电子发票。
- **退款售后**：学习进度不超过 10% 的已支付订单可申请退款，提交后等管理员审核，通过后原路退回。
- **收益结算**：讲师可看累计收益、退款冲销、已提现、可提现余额，按日查看报表与明细，
  实名认证后可申请提现。

### 👤 个人中心
六个标签页：**资料**（昵称/头像/签名、绑定邮箱手机号）、**实名与讲师**
（提交实名认证、申请成为讲师、关注与粉丝列表）、**我的记录**（发帖/点赞/上传/购买/学习）、
**通知**（点赞评论关注@提及与系统消息）、**私信**（一对一沟通）、
**账号安全**（改密码 + 强度提示、账号注销）。
点任意用户的名字可以进**用户主页**，看他的发言、关注数、粉丝数并一键关注。

### 🎓 讲师工作台
- **课程管理**：创建课程（标题/简介/分类/类型/价格/有效期），给课程添加章节与课时，
  把某个课时勾选为「试看」，然后上架。
- **我的直播**：查看自己的场次，直接进入直播间控场。
- **学员**：报名记录与学习进度。
- **评价与问答**：查看学员评价、回复学员提问。
- **收入明细**：日收益报表 + 订单级明细 + 提现申请。

### ⚙️ 管理后台（用 `admin` 登录）
- **数据看板**：用户/内容/交易三组核心指标，近 14 天趋势图，课程分类分布。
- **审核队列**：举报、待审新闻（可「立即从可信源抓取」）、讲师申请、实名认证、
  退款、提现、发票 —— 所有需要人工处理的事情集中在这里，每项都能一键通过/驳回。
- **用户管理**：搜索筛选、封禁解封、设为讲师、查看用户主页。
- **内容管理**：帖子置顶/加精/隐藏，课程强制下架。
- **交易对账**：订单流水（含风控标记）、退款记录、提现记录。
- **运维工具**：访问日志查询、一键备份与恢复、导出全库 JSON、
  全站公告推送、清理回收站、关闭超时订单、重置演示数据。

## 四、常见问题

**Q：忘记密码了？** 登录页「忘记密码」标签页输入注册邮箱收验证码重置（演示环境验证码直接显示在页面上）。

**Q：为什么登录提示账号锁定？** 连续输错 5 次会锁定 10 分钟，这是需求里明确要求的账号保护策略。

**Q：买课提示要实名认证？** 购课、开课、提现都需要实名，去「个人中心 → 实名与讲师」提交，
然后用管理员账号在「管理后台 → 审核队列 → 实名认证」通过即可。

**Q：数据存在哪？会丢吗？** 存在 `data/bgl.db`（SQLite 单文件）。管理员可以在
「运维工具 → 备份与恢复」里一键备份、导出 JSON 或从备份还原。

**Q：短信/邮件/支付是真的吗？** 是**本地模拟**的，界面上都标注了「演示模式」，
验证码直接显示在页面上。真实接入方式见 `README.md` 第六节（演示模式说明）。

**Q：怎么改端口？** 命令行执行 `set BGL_PORT=8600`（Windows）或 `export BGL_PORT=8600`，再启动。

**Q：想重新来过？** 管理后台「运维工具」里有「重置演示数据」，会清空并重建一份干净的演示数据。

## 五、想分享给别人用？（部署上线）

上面讲的都是"自己电脑上打开"。要让别人从**公网**访问，需要用部署入口：

```bash
python tools/deploy_sync.py     # 生成干净部署包 dist_deploy/（约 0.7 MB，可安全上传）
PORT=8501 python serve.py       # 或用 bash serve.sh
```

三件事和本地版不一样，但都已经在代码里处理好了：

1. **端口**由平台通过环境变量 `PORT` 指定，`serve.py` 自动读取并绑 `0.0.0.0`；
2. 平台域名和容器端口不同源，`serve.py` 已关掉 CORS / XSRF 校验，否则页面会一直"正在连接…"；
3. 云端 `data/` 是空的，**首次打开会自动建库并灌好演示数据**，登录即可用。

> 上传时**不要**整个文件夹打包：`.venv/` 有 350MB 且平台会自己装依赖。
> 只要上传 `python tools/deploy_sync.py` 生成的 `dist_deploy/` 目录即可。

完整的部署方式对比（平台一键发布 / Streamlit Cloud / 自建服务器）、启动命令速查与
**故障排查表**见同目录下 **`部署上线说明.md`**。
